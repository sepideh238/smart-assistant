# Smart Assistant

A responsive React and Vite project focused on product search, comparison, and a clean user experience.

---

## Overview

Smart Assistant is a frontend application designed to help users search products, view results, compare selected items, and follow a simple recommendation flow.

This version focuses on UI refinement, modal-based comparison, and smooth interactions.

---

## Features

- Product search flow
- Results page
- Reusable product cards
- Compare modal
- Comparison page
- Mockup-based UI
- Smooth and subtle transitions
- Responsive SCSS styling

---

## Tech Stack

- React
- Vite
- SCSS
- React Router
- Local mock data
- React hooks

---

## Version 2 Highlights

- Improved the UI based on a mockup
- Refined transitions for a softer user experience
